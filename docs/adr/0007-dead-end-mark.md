# ADR 0007 — 行き止まりの奥の壁に ? を出す

- 状態: 受理
- 日付: 2026-10-25
- Issue: #37
- 影響する規則: ARC-001 / ARC-007 / ARC-012

## 文脈

ADR 0006 は部屋の一歩を 112ms にし、行き止まりは特別にしないと書いた。突き当たりの床は出口が一つで、次の一歩は来た道を戻る。広い階ではその絵が 14ms か 28ms で過ぎ、奥の壁はただの線に見える。施主は行き止まりの `?` を残している。開いた文献は、開いた升に立ったまま壁を見せ、壁の中へ進まない。

## 決定

出口が一つだけで、その出口をすでに踏んでいる床にいるとき、来た方向の反対の壁に `?` を一つ出す。平面は走者と同じ明るい文字、疑似 3D はその壁の中央に一つ置く。走者は `@` のまま動かない。その升から戻る一歩の待ちは少なくとも `StepPace.wonder` の 167ms である。すでに長い待ちは縮めない。先がまだ開いている入口、足を止めている拍、通路の直線は変えない。3D の途中の 4 枚と、向きを変える拍は残す。`forSpan` は変えない。

## 強制

行き止まりかどうかは `DeadEnd` だけが決め、待ちを延ばすのは `WalkTempo` だけである。文字は `ScreenText.wonder` だけが持つ。次に動くかは `FloorReducer.tick` の結果だけを見る。ゲートは、奥の壁が `?`、入口には出ない、戻る待ちが 167ms、通路の直進が 14ms、戦闘が階の歩調であることをテストする。

## 結果

突き当たりでは奥の壁に `?` が見え、平面でもその拍は 167ms になる。まだ進める通路の入口には出ない。階段の前、上り、掘削は、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 壁の升へ一歩進めてから `?` を出す | 開いた升に立ったまま見せる、という文献の形を外れる |
| 近い壁を画面いっぱいの面にする | 距離ゼロの面は、レンズが石の中に入った絵になる |
| 出口が一つの升すべてに出す | まだ先へ進める入口まで行き止まりに見える |
| 待ちを 112ms のままにする | 広い階の平面では `?` を読めない |
| 戦闘の拍も 167ms にする | 足を止めている長さが階の歩調から外れる |
