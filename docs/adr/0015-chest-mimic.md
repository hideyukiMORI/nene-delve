# ADR 0015 — 宝箱の一部がミミックになる

- 状態: 受理
- 日付: 2026-10-25
- Issue: #53
- 影響する規則: ARC-001 / ARC-007 / ARC-011 / ARC-012

## 文脈

封印の宝箱は `$` で、開けると経験値と火花が出る。見た目が同じ宝箱が、開けると敵になる余地は残っていた。

宝箱、湖、敵、罠、ワープの位置は `FloorFixtureField.placed` の乱数列で決まっている。ADR 0013 は、その列をボスより前に引き終えている。ADR 0014 はミミックをこの決定の外に置いている。

## 決定

広い階に置いた宝箱のおよそ 3 分の 1 をミミックにする。抽選はワープのあとで、宝箱の升は動かさない。宝箱が無い階にはミミックも無い。封印中の記号と色は普通の宝箱のままである。

踏むと経験値も火花も出さない。その宝箱は開き、北、東、南、西の順で空いている床へ、追わない敵が飛び出す。空いていなければ、その升に出る。体力は、同じ深さで追わない敵と同じ式である。戦闘は既存の拍で、6 拍で倒していなければ退く。

一言は `MIMIC $` である。文言は Render が持つ。戦闘中の記号は `$` と `&` を交互に、脅威の色で出す。平面と疑似 3D は同じ記号を使う。

## 強制

印は `FloorFixture.mimic` だけが持つ。付けるのは `ChestMimic.disguise` だけである。飛び出す升は `ChestMimic.stand` だけが決める。戦闘は `DelverBout`、個体は `FloorProwler` のミミック用の初期化子である。記号は `ScreenText.foeGlyph`、文言は `DelverCopy` の `.mimic` だけが作る。Render は時計を読まない。

ゲートは、広い階の一部だけがミミックを持つこと、湖と罠とワープには付かないこと、踏んでも経験値と火花が出ず隣へ飛び出すこと、次の拍が `MIMIC` と言い体力が減ること、体力の多い個体が最後の拍で退くこと、封印中は戦利品の `$`、戦闘中は脅威の `$` と `&` であることをテストする。

## 結果

宝箱のおよそ 3 分の 1 が、開いた瞬間に噛みつく。同じシードの宝箱の位置は変わらない。他の宝箱が残っていれば、階段はまだ塞がる。踏んだミミック自身は開いた宝箱として扱う。歩調、消失点、掘削、ボス階、最深記録は変えない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 宝箱とは別の種類にする | 封印中は宝箱である。種類を増やすと、火花と階段の分岐が二つになる |
| 配置の乱数をワープより前に使う | 同じシードの湖、敵、罠、ワープの位置が変わる |
| 封印中から `&` を点滅させる | 開けるまで宝箱と見分けない |
| 経験値と戦闘を両方出す | ミミックは宝箱の中身ではない |
| 6 拍で退かせない | 深い階で歩みが止まらない。ボスは別の個体である |
| 体力の式を新しくする | 追わない敵の式をそのまま使う |
| 新しい拍の長さ、または `FloorTick` | 戦闘の待ちは既にある。階の入れ替えは `changed` のままである |
| HUD に行を足す | 5 行のままである |
| `FloorProwler` の既存の初期化子に引数を足す | 引数は 4 つまで。ミミックは別の初期化子が持つ |
| 迷路タイプ C–L を同じ変更に混ぜる | 提案のままである |
