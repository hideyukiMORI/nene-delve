# ADR 0005 — 直線の一歩だけ 14ms にする

- 状態: 受理
- 日付: 2026-10-25
- Issue: #33
- 影響する規則: ARC-001 / ARC-007 / ARC-012

## 文脈

一歩の待ちは `StepPace.forSpan` だけで、28ms から 80ms のあいだにある。同じ方向へ続く通路も、角も、同じ待ちである。広い階はすでに 28ms なので、直線をそれ以上短くできない。ADR 0003 は 3D の途中を 4 枚、静止を 167ms とし、ADR 0004 はその待ちを変えないと書いた。施主は直線のダッシュを残している。

## 決定

直前の一歩と同じ方向へ進むときだけ、待ちは `StepPace.dash` の 14ms である。3D でも途中の 4 枚は描き、その待ちと直線上の静止を 14ms にする。最初の一歩、方向が変わる一歩、足を止めている拍は階の歩調のままである。向きを変える拍は 167ms のままである。`forSpan` は変えない。

## 強制

直線かどうかは `WalkLine` だけが決め、次の位置は `FloorReducer.tick` の結果だけを見る。実行ファイルは時計を読んで待ちを選ばない。ゲートは、続く世界が 14ms、出発と折れと戦闘が階の歩調、広い階の `forSpan` が 28ms であることをテストする。

## 結果

広い階の平面でも、通路を直進するあいだだけ一歩が 14ms になる。角と戦闘は読める速さを残す。3D の途中の絵は残るので、直線は同じ 4 枚をより短く見せる。部屋、行き止まり、階段の前は、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 直線で 3D の途中の絵を消す | 速さをフレームの間引きで作ることになる。絵は残し、待ちだけを変える |
| `forSpan` の下限を 14ms にする | 角まで同じ速さになり、広い階の全体が追えない |
| 直線を 28ms のままにする | 広い階では今と変わらず、ダッシュが見えない |
| 実行ファイルが通路の形を自分で見る | 直線の意味が二つになる |
