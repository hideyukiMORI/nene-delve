# ADR 0016 — 迷路の型を洞窟から街区まで増やす

- 状態: 受理
- 日付: 2026-10-25
- Issue: #55
- 影響する規則: ARC-001 / ARC-007 / ARC-011 / ARC-012 / SWF-002

## 文脈

階の種類は `MazeKind.chosen` の一つだけが決めていた。`SplitMix64` の次の値が偶数なら完全迷路、奇数なら部屋である。生成器自身の乱数は進まない。

同じ式をこの変更の前の規則で読むと、起動シード 1 の B1F は部屋、起動シード 9 の B1F は完全迷路である。種類を増やすと同じシードの割り当てが変わる。割り当てを種類の数だけ何度も変えないため、この変更は一つの Issue にまとめる。

この版の B1F を `MazeFactory.make` で測ると、起動シード 1 は動く壁で明かりがあり、起動シード 9 は洞窟で明かりがある。10 階は、起動シード 1 が階シード 7455107161863376737 の完全迷路、起動シード 9 が階シード 10878741101378410912 のループで、どちらも明かりがある。起動シード 0 以上 40 未満の B1F のうち 11 個が暗い。同じシードの再現は、この版の中での話である。

## 決定

種類は 11 で、抽選順は部屋、完全迷路、洞窟、ループ、回路、ラック、島、柱、渦巻き、動く壁、街区である。`chosen` は階シードの `SplitMix64` を一つ進め、値を 11 で割った余りでこの順を引く。

暗闇は種類ではない。`MazeFactory.make` だけが、種類の抽選とは別の `SplitMix64` を二つ進めた値が 4 の倍数のとき、その階を暗くする。半径 4 のマンハッタン距離の外の床と階段は、描画のときだけ壁に見える。探索の迷路は変えない。`rooms()` と `filled()` は闇を掛けず、升は同じ種類の `make` と一致する。

動く壁は完全迷路に、行き止まりの先の壁を候補として載せる。最初はどれも閉じている。歩数が 24 の倍数のときだけ一つ開き、次の周期でそれを戻して次を開く。人が立っている升、敵の升、仕掛けの升は閉じない。開いた升は掘削の記録に足さない。周期は歩数であり、時計は読まない。

回路の交差はワープではない。ラックの横通りと島のまわりの壁は湖ではない。タイルは壁、床、階段のままである。部屋の 112ms は種類が部屋のときだけである。宝箱、湖、敵、罠、ワープの乱数列と、ボスの広間と、歩調は変えない。

## 強制

種類を足すときは `MazeKind` のケースと `order` と `MazeFactory` の分岐を一緒に足す。分岐に `default` は書かない。闇を掛けるのは `FloorShade.applied`、描画で隠すのは `DarkFloor.masked`、壁を動かすのは `ShiftWall.turn` だけである。`FramePainter.paint` は掘削のあとに `masked` を通す。引数は 4 つのままである。

ゲートは、どの種類でも開始から階段へ届くこと、同じシードが同じ迷路になること、直接の部屋と完全迷路が闇なしであること、シード 0 以上 40 未満に闇と明かりが両方あること、ループと洞窟が完全迷路より開き、洞窟と柱と島とラックが内部の壁を残すこと、渦巻きが分岐しないこと、街区が回路より閉じていること、動く壁が 24 歩目で一つ開き、立っている升を閉じないこと、闇が探索の迷路を変えないこと、遠い床が描画で隠れることをテストする。

## 結果

起動シード 1 の B1F は部屋から動く壁へ、起動シード 9 の B1F は完全迷路から洞窟へ変わる。直接 `rooms()` と `filled()` を呼ぶテストの升は変わらない。新しい種類は部屋の待ちを使わない。幅 40 の HUD が長いシードで最深記録を落とすこと、Windows Terminal の見た目が未確認であることは、この決定の外である。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 種類ごとに `chosen` を変える | 同じシードの階が、種類の数だけ割り当て直される |
| 暗闇を種類にする | どの形にも重なる修飾である。抽選が形と暗さを一度に決めてしまう |
| 暗い床を探索の壁にする | 還元と探索が、本当の迷路を読めなくなる |
| `paint` に闇の引数を足す | 引数は 4 つまでである |
| 回路の交差をワープにする | ワープは ADR 0011 の同じ階のパッドだけである |
| 横通りや島の海を湖、または新しいタイルにする | 湖は `FloorFixture.lake` だけである。タイルは壁、床、階段だけである |
| 動く壁を時計で進める | 周期は歩数 24 である。生成器も描画も時計を読まない |
| 開いた升を掘削の記録に足す | 最後の掘削フレームが、一時的な開口を掘ったことにする |
| 人が立っている升を閉じる | 探索が壁の中に残る |
| `rooms()` と `filled()` にも闇を掛ける | 直接の呼び出しは部屋と完全迷路のままである。闇は `make` だけが掛ける |
| 歩調、宝箱の乱数列、ボスの広間、HUD の行数を変える | この決定の外である |
| 部屋の待ちを新しい種類にも掛ける | 待ちは種類が部屋で、床か階段の 2 升四方のときだけである |
