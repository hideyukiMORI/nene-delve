# ADR 0006 — 部屋の一歩は少なくとも 112ms にする

- 状態: 受理
- 日付: 2026-10-25
- Issue: #35
- 影響する規則: ARC-001 / ARC-007 / ARC-012

## 文脈

ADR 0005 は、同じ方向へ続く一歩だけを 14ms にし、部屋は特別にしないと書いた。広い階の通路は 14ms か 28ms なので、部屋を横切るあいだも眺められない。施主は部屋でゆっくりを残している。部屋の矩形は生成のあと迷路の升へ畳まれ、種類が `rooms` のときだけ残る。

## 決定

種類が `rooms` で、いまの升が床か階段の 2 升四方に含まれるとき、その升から動く一歩の待ちは少なくとも `StepPace.linger` の 112ms である。すでに 112ms より長い待ちは縮めない。通路の直線は 14ms のまま、足を止めている拍は階の歩調のまま、向きを変える拍は 167ms のままである。3D の途中の 4 枚は残し、部屋のときだけその待ちを 112ms まで延ばす。`forSpan` は変えない。

## 強制

部屋かどうかは `RoomSpan` だけが決め、待ちを延ばすのは `WalkTempo` だけである。次に動くかは `FloorReducer.tick` の結果だけを見る。実行ファイルは時計を読んで待ちを選ばない。ゲートは、部屋の直進が 112ms、通路の直進が 14ms、部屋の戦闘が階の歩調、167ms が縮まないこと、升目だけの迷路が部屋にならないことをテストする。

## 結果

広い階の平面では、部屋の中だけ一歩が 112ms になり、通路の直線は 14ms のままである。疑似 3D の静止がすでに 167ms のときは、部屋でも 167ms のままである。行き止まり、階段の前、上りは、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 部屋で 3D の途中の絵を消す | 速さをフレームの間引きで作ることになる。絵は残し、待ちだけを変える |
| 部屋の待ちを 167ms より短くして静止を置き換える | 部屋に入っただけで、向きを見る時間まで短くなる |
| 生成時の矩形を迷路に保存する | 升から読める部屋と、保存した矩形の二つになる |
| 升目の迷路も 2 升四方だけで遅くする | 種類 B に部屋は無い。幅が 1 の通路までゆっくりになる |
| 足を止めている拍も 112ms にする | 戦闘と足場の長さが階の歩調から外れる |
