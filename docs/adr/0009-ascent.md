# ADR 0009 — 上りの階段で一つ上の階に戻る

- 状態: 受理
- 日付: 2026-10-25
- Issue: #41
- 影響する規則: ARC-001 / ARC-007 / ARC-012

## 文脈

階は `FloorIndex.deeper` と `FloorReducer.nextFloor` で深くなるだけである。画面は `B1F`、`B2F` と増える。施主の残りは上りである。上の階の迷路は起動シードと深さから `Seed.forFloor` で作り直せる。歩いた升の履歴は持たない。ADR 0008 は下り階段の手前だけを 7ms にし、上りは特別にしないと書いている。

## 決定

B1F には上りを置かない。2階より深い階は、開始地点でも下り階段でもない床のうち、下り階段から最も遠い升を一つ `<` にする。同距離は y が小さく、次に x が小さい升を取る。その升のタイルは階段である。

深さ 3、6、9… の階で、まだその深さから上っていなければ、宝箱を開けたあと `<` に着くと一つ上の階へ戻る。戻った階は同じ起動シードと深さから作り直し、数値を引き継ぎ、下りと同じだけ休む。上った深さは走者が覚え、同じ深さにはもう一度上らない。それ以外の階は `<` を通り抜け、`>` で降りる。

上りの一歩は下り階段の 7ms にしない。旋回と、階が変わったあとの待ちは 167ms のままである。

## 強制

上りの位置と、この訪問で上るかどうかは `AscentSite` だけが決める。階の進みと戻りは `FloorReducer` だけが行う。実行ファイルは時計を読んで上る階を選ばない。ゲートは、B1F に上りがないこと、3 の倍数の階だけが一度上ること、宝箱が先であること、戻った迷路が同じシードのその階と一致すること、2 階は `<` を通って `>` に着くこと、平面と疑似 3D が `<` と `>` を描き分けることをテストする。

## 結果

画面の階層が、B3F のあと一度 B2F に戻ってから、また深くなる。同じ階の往復で先へ進めなくならない。B1F の経路は変えない。ワープ、掘削、降りる演出は、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 上の階の迷路を履歴として持つ | 同じシードと深さで作り直せる。履歴は二つ目の経路になる |
| B1F にも `<` を置く | 上の階がなく、B1F を歩く既存のテストの意味が変わる |
| どの深い階でも `<` を終点にする | 2 階で B1F に戻り、先の階へ進まなくなる |
| 同じ深さから何度でも上る | B3F と B2F を往復して、それより深くならない |
| 床のまま記号だけ変える | 疑似 3D の階段は階段タイルで止まる。床のままでは `<` が柱にならない |
| `<` を開始地点に置く | 開始地点は踏んだあとの升であり、引き返す一歩は到着にならない |
| 上りの一歩も 7ms にする | 下り階段の手前だけを短くする決定を広げない |
| 旋回や降りたあとの 167ms を短くする | 向きを見る拍と、階が変わったあとの絵が消える |
