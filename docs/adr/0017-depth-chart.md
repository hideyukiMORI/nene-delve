# ADR 0017 — 疑似 3D の右上に近い地形を出す

- 状態: 受理
- 日付: 2026-10-25
- Issue: #61
- 影響する規則: ARC-001 / ARC-011 / ARC-012 / SWF-002

## 文脈

疑似 3D は視線の絵である。正面の壁が 4 升より遠いと壁の帯は 1 行以下になり、大部屋では升の並びが読めない。HUD 最上段には向きが `N` `E` `S` `W` の 1 文字で、座標が `X` `Y` で出る。近くの壁と床は出ていない。施主は、3D では方角と、右上の近い範囲の図が無いと分かりにくい、と指摘した。

## 決定

疑似 3D の迷路面（HUD の 5 行の下）の右上に、走者を中心とした近景を重ねる。一辺は 5 升で、画面の幅か高さがそれより狭いときは 3 以上の奇数に縮め、3 未満なら出さない。図の上が向いている方向、右が右手である。中央は走者 `@`。各升の文字は平面と同じ `FramePainter` の升決定を使う。行き止まりの `?` だけは近景に写さず、3D の壁に一つ残す。平面には重ねない。HUD の行数と方角の文字は変えない。

## 強制

升の対応は `DepthChart` だけが決める。文字は平面の升決定を呼び、近景専用の字形を持たない。`?` を近景から外す例外は、3D の壁にある一つの `?` を二重にしないためである。ゲートは、四方向で正面と右が隣の升であること、図の中央が `@` で正面が平面と同じ文字であること、平面の右上に図が出ないこと、狭い画面が 5 から 3、2 未満は 0 になることをテストする。

## 結果

3D の右上で、正面の床と左右の壁が平面と同じ文字で読める。方角の絶対方位は今まで通り HUD の 1 文字である。近景は半径 2 升までで、階全体は出ない。暗い階では明かりの外が壁として見えるのは、平面と同じマスクである。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 北を上にする | 3D の正面と図の上が一致せず、向きを頭の中で回すことになる |
| HUD の右に図を置く | 最上段の右は座標と時刻が使っている。HUD は 5 行のままにする |
| 方角を `NORTH` などの語にする | `N` `E` `S` `W` が既にある。2 つ目の表示を足さない |
| 階全体を縮小して右上に置く | 広い階では点が潰れる。施主が求めたのは近い範囲である |
| Unicode の枠で囲む | 幅が曖昧になる |
| `paint` に第 5 引数を足す | 引数は 4 つまで |
| 平面にも同じ図を重ねる | 平面は地図そのものである |
| 行き止まりの `?` も近景に写す | 3D の壁の `?` と合わせて二つになり、一つという既存の絵が壊れる |
