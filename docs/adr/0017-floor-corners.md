# ADR 0017 — 大部屋の床に升の角を置く

- 状態: 受理
- 日付: 2026-10-25
- Issue: #57
- 影響する規則: ARC-011 / ARC-012 / SWF-002

## 文脈

疑似3Dの壁の帯は、描画の高さを垂直距離の 3 倍で割った行数である。80×24 では、壁がおよそ 4 升より遠いと帯が 1 行以下になり、残るのは天井と 3 段の床である。ボスの広間、洞窟、柱の間がこの距離に入る。水たまりと宝箱は点なので、広い床は空白のままである。

## 決定

壁までの垂直距離が 4 以上の列だけ、開いている升が接する角に `,` を一つ置く。同じ画面の升へ重なるとき、および 6 列かつ 2 行より近いときは、近い角を残す。文字の地は、その升の床か水の色のままである。文字色は壁の色である。

## 強制

角を置くのは `DepthGrain.dots` だけである。`DepthScene` は、床が空白の升にだけそれを書く。水の縁、階段、宝箱、敵が先に書いた文字は残す。`DepthGrain.reach` は 4 である。Render は時計を読まない。

ゲートは、壁が 4 升より近い絵に `,` が無いこと、広い床の絵に `,` が 8 つ以上あり横線が無いこと、文字色が壁の色であることをテストする。

## 結果

遠い床に升の大きさが出る。近い通路の床は今の 3 段のままである。迷路の形、宝箱の位置、歩調は変わらない。角は点なので、柱のような近い壁面はまだ無い。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 床の升を線でつなぐ | 地平線の近くで升が 1 行に潰れ、ノイズになる |
| `-` を使う | 疑似3Dの床から横線を消してある。水の縁も `-` である |
| 色の差だけで床を分ける | 水たまりがすでにそれで広い床に溶けている |
| 近い壁の列にも置く | 通路は壁の帯だけで読める |
| 宝箱を増やす | 点が増えるだけで、床の広さは読めない |
| 柱を迷路に足す | 迷路の形、到達、ボスの広間が変わる。この決定の外である |
