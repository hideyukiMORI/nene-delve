# ADR 0011 — 同じ階の二つのパッドで場所を飛ばす

- 状態: 受理
- 日付: 2026-10-25
- Issue: #45
- 影響する規則: ARC-001 / ARC-007 / ARC-011 / ARC-012

## 文脈

階の入れ替えは `FloorReducer.nextFloor` と `previousFloor` だけが行う。罠は HP を減らし、`snareSpan` の 4 拍止まる。宝箱が開くときは戦利品の色の火花が出る。ADR 0008、0009、0010 はワープをその決定の外に置いている。施主の絵は、一瞬グリッチして別の場所へ飛ぶパッドである。階層を飛ばすことではない。

封印された仕掛けは、いま階段を塞ぐ。罠もその中に入る。パッドを同じ扱いにすると、罠に加えて遠回りが増え、歩数の上限に届かない階が出る。パッドを開いたまま往復させると、同じ対を行き来して行き詰まる。

## 決定

同じ階に、封印されたパッドを二つ置く。広い階のおよそ 3 回に 1 回である。空いた床が二つ無い階には置かない。片方を踏むとその一歩で、もう片方へ移動する。両方とも開き、もう一度は飛ばない。階層は変わらない。着地のあと `warpSpan` の 4 拍、その場で止まる。この待ちは既存の足踏みであり、歩調には通さない。

宝箱が先である。上る階では、宝箱のあと上りの階段がパッドより先である。それ以外は、開いた宝箱のあと一番近いパッドへ寄る。パッドは階段を塞がない。罠が塞ぐ振る舞いは変えない。

配置は宝箱、湖、敵、罠の抽選のあとである。それらの位置は動かさない。開始地点、階段、それらの仕掛けの升には置かない。対の片方は残った床から引き、もう片方はそこからマンハッタン距離が最も遠い床である。同距離は行の走査で先の升を取る。

平面は `o` と `0` を点滅する。飛んだ数拍は、走者の上下左右の開いた升に `o` `0` `#` `%` をテーマの計器色で出す。宝箱の火花が同じ升なら火花が残る。疑似 3D は封印中だけ同じ点滅の柱にし、飛んだあとは位置が移ることと HUD の `>> VIA o` で見せる。消失点は動かさない。HP、MP、EXP は変えない。

## 強制

対の位置と、一度きりの移動は `FloorFixtureField` と `FloorReducer` だけが決める。階の入れ替えは足さない。記号は `ScreenText` だけが持つ。Render は時計を読まない。ゲートは、広い階で対が付くことと付かないこと、同じシードで同じ対になること、一度だけ飛んで 4 拍止まること、パッドが階段を塞がないこと、平面と疑似 3D が記号を出すことをテストする。

## 結果

同じ階の別の床へ、一度だけ飛ぶ。階層の数は、深くなるか、上りの階段で戻るだけである。掘削、ボス階、最深記録、宝箱のミミックは、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 階層を飛ばす | 絵は別の場所である。階の入れ替えを二つ目の関数にしない |
| パッドを開いたまま往復させる | 同じ対を行き来し、歩数の上限で行き詰まる |
| 宝箱の火花を使う | 戦利品と区別できない |
| 使うまで階段を塞ぐ | 罠がすでに塞ぐ。遠回りが重なり、階段に届かない |
| 上る階でもパッドを先に寄る | 下り階段に乗って、上るべき階を降りてしまう |
| 新しい歩調を足す | 止めて見せる時間は、既存の足踏みで足りる |
| 迷路の種類 E として置く | 種類 C–L は提案のままである。パッドは A と B の床に置く |
| 消失点をずらす | 水平線が動くのは、階が変わるときだけである |
| `paint` に引数を足す | 引数は 4 つまで。パッドは仕掛けと一言が持つ |
| 敵の抽選より前に乱数を引く | 同じシードの敵の位置が変わる |
