# ADR 0013 — 10 階ごとに大部屋とボスを置く

- 状態: 受理
- 日付: 2026-10-25
- Issue: #49
- 影響する規則: ARC-001 / ARC-007 / ARC-011 / ARC-012

## 文脈

節目の階に、通常より大きい部屋と一体のボスが欲しい。敵は `FloorProwler`、戦闘は `DelverBout`、階の生成は `MazeFactory` の一つである。仕掛けの位置は `FloorFixtureField.placed` の乱数列で決まっている。

ADR 0012 は、着地のたびに掘削記録の順で壁を開ける。記録の末尾を足せば、最後の枚は完成した迷路のままである。ボス階を別の生成器にすると、同じシードの床が二つになる。

## 決定

深さ 10 以上で 10 の倍数の階だけ、仕掛けを置いたあとに中央の長方形を開ける。幅は `min(幅-2, max(9, 幅*2/3))`、高さは `min(高さ-2, max(7, 高さ*2/3))`、原点は内法の中央である。壁だけを床にし、その順を掘削記録の末尾に足す。階段と外枠は残す。開く壁が無ければ、迷路もボスも増やさない。

ボスは開いた升のうち、長方形の中央にマンハッタン距離で最も近い升に 1 体置く。同距離は、行優先で先の升を残す。追わない。体力は、同じ深さで追う敵の 2 倍である。戦闘の 6 拍では退かず、倒れるか走者が倒れるまで同じ拍を続ける。

誘導は、未開の宝箱、点滅しているボス、上る階の上り階段、武装したワープ、の順である。30 階のように上る階でも、上りの規則は残す。ボスは階段を塞がない。

## 強制

大部屋は `BossHall` だけが開ける。階の組み立ては `FloorReducer.makeWorld` のままである。仕掛けの乱数は、開ける前の迷路に対する `placed` のままである。体力の式は `DelverVitals.bossLife`。記号は `ScreenText.boss`。Render は時計を読まない。

ゲートは、9 階が開かないこと、10 階で記録の末尾が開いた壁と一致し最後の枚が完成と一致すること、10 階の仕掛けが開ける前と同じこと、ボスが 1 体で追わず中央に立つこと、6 拍後も戦闘が続くこと、体力 1 のボスが 1 拍で消えること、平面の記号が `B` であること、上る階では宝箱の次にボスへ向かい上りを残すことをテストする。

## 結果

10 階ごとに、中央の大部屋と `B` のボスが増える。通常の階の迷路と仕掛けは変わらない。部屋種の階では、大部屋の一歩は既存の 112ms になる。歩調の数は変えない。深い階では、ボスの打撃で走者が倒れることがある。これは既存の式のままである。最深記録と宝箱のミミックは、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 別の迷路の種類、または種類 E | 種類 C–L は提案のままである。ビアは同じ階のパッドとして既にある |
| 第二の生成器 | 完成した迷路が二つになり、同じシードの床が変わる |
| 大部屋を開けてから仕掛けを置く | 候補の床が増え、同じシードの宝箱と敵の位置が変わる |
| ボスの抽選を通常の敵より前に引く | 同じシードの敵の位置が変わる |
| 6 拍で退かせる | 通常の敵と同じで、ボスにならない |
| 歩調、消失点、掘削の枚数を変える | 14ms、112ms、167ms、7ms、80ms、40 枚はこの絵とは別である |
| ボスの階で消失点を動かす | 水平線が動くのは、階が変わるときだけである |
| Render が時計を読む | 待ちは実行ファイルだけが持つ |
| 階段を塞ぐ | ボスは床の敵である。上りの意味は変えない |
| `paint`、`Maze`、`FloorProwler`、`FloorFixtureField` に引数を足す | 引数は 4 つまで。ボスは別の初期化子が持つ |
| 新しい一言の種類、または `FloorTick` | 遭遇の一言は既にある。階の入れ替えは `changed` のままである |
| 最深記録、ミミックを同じ変更に混ぜる | 一つずつ着地する |
