# ADR 0012 — 階に着くと壁が掘られていく

- 状態: 受理
- 日付: 2026-10-25
- Issue: #47
- 影響する規則: ARC-001 / ARC-007 / ARC-011 / ARC-012

## 文脈

迷路は着いた時点で完成している。`CarveState` と `RoomMaze` は一度に掘り、実行ファイルは完成した `FloorWorld` をすぐ描く。施主の絵は、階に着くたび数秒、壁が掘られていく様子である。

ADR 0010 は、階が変わるときだけ消失点をずらし、そのあと次の階を中央で 167ms 待つ。ADR 0011 は同じ階のパッドで、掘削は特別にしないと書いている。歩調はこの絵とは別である。

## 決定

階に着くたび、いまの掘削順の前から壁を開ける。B1F の開始、下り、上りを含む。完成した迷路は `MazeFactory` の出力のままである。記録は、最初に床になった升だけを、その順で `MazePlate` に残す。

枚数は 40 である。最後の枚は記録の全部を開ける。開始地点は常に開ける。記録が空の迷路は、最初から完成として描く。1 枚の待ちは前進の途中と同じ 80ms で、`WalkTempo` には通さない。平面と疑似 3D の両方で、水平線は中央のままである。

まだ開いていない床と階段は壁として描く。その壁の上に宝箱、敵、行き止まりの `?` は出さない。世界は進めない。

平面では、階段の上の絵を 167ms 見せたあと掘る。掘り終わったら通常の歩調に戻る。疑似 3D では、消失点の 4 枚のあと、完成した次の階を先に出さない。掘り終わった中央の絵を 167ms 待つ。この 167ms は、迷路が完成したあとの最初の待ちであり、ADR 0010 の到着の待ちのままである。

## 強制

掘削順は `CarveState` と `RoomMaze` だけが足す。見せる迷路は `DigReveal` だけが作る。枚数は `DigReveal.frames`。待ちは実行ファイルの `DepthHold.slice`。階の入れ替えは `changed` のまま。Render は時計を読まない。

ゲートは、同じシードで同じ順になること、枚が進むと開いた升が増えるだけであること、最後の枚が完成と一致すること、空の記録は完成のままであること、上りの迷路が記録を保つこと、平面の最初の枚が開始地点に走者を出し未開の隣を壁記号にすること、疑似 3D の最初の枚が完成と違うこと、掘っているあいだ `?` を出さないことをテストする。

## 結果

階に着くたび、約 3 秒、壁が開いていく。完成した迷路、歩調、消失点、仕掛けの位置は変わらない。ボス階、最深記録、宝箱のミミックは、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 別の生成器で掘る | 完成した迷路が二つになり、同じシードの床が変わる |
| 行の順に拭う | 掘った順ではない |
| 迷路の種類 E | 種類 C–L は提案のままである。ビアは同じ階のパッドとして既にある |
| 歩調を変える | 14ms、112ms、167ms、7ms はこの絵とは別である |
| 167ms を短くする | 迷路が完成したあとの待ちを消さない |
| 掘っているあいだ消失点を動かす | 水平線が動くのは、階が変わるときだけである |
| Render が時計を読む | 待ちは実行ファイルだけが持つ |
| 階段を塞ぐ仕掛けにする | 掘削は描画である。階段の意味は変えない |
| `paint` や `Maze` に引数を足す | 引数は 4 つまで。記録は `MazePlate`、枚は `FrameLook` が持つ |
| 敵の抽選より前に乱数を引く | 同じシードの敵の位置が変わる |
| `FloorTick` に掘削を足す | 世界は進まない。拍は実行ファイルが持つ |
| ボス階、最深記録、ミミックを同じ変更に混ぜる | 一つずつ着地する |
