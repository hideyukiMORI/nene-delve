# ADR 0010 — 階が変わるときだけ消失点をずらす

- 状態: 受理
- 日付: 2026-10-25
- Issue: #43
- 影響する規則: ARC-001 / ARC-007 / ARC-012

## 文脈

ADR 0003 は視線を向き、論理座標、前進の割合とし、静止の目をマス中心より 0.46 後ろに置く。壁帯の縦位置は画面の中央である。前進は目を前へ滑らせるだけで、水平線は動かない。ADR 0009 は上りの階段を足し、降りる演出は特別にしないと書いている。

施主は、上り下りでは消失点が動くのが適切な表現だと確認した。普段の歩行まで動かすと、廊下と階段が同じ絵になる。平面の地図に消失点はない。歩調と、旋回と到着の 167ms は、この絵とは別である。

## 決定

疑似 3D で階が変わるときだけ、消失点を動かす。降りるときは上へ、1 行から 4 行まで。床が広がる。上るときは下へ、同じ行数だけ。天井が広がる。1 枚の待ちは前進の途中と同じ 80ms で、`WalkTempo` には通さない。

4 枚のあと、次の階を中央の水平線で描く。階が変わったあとの待ちは 167ms のままである。普段の一歩、旋回、4 枚の前進は中央のままである。平面は記号と階の数字のままで、途中で平面に切り替えても階の移動は終わらせる。HUD の 5 行は動かさない。

## 強制

壁帯の縦位置は `DepthPlane` だけが決める。行の向きと量は `DepthPitch` だけが決める。枚数と待ちは実行ファイルの `DepthHold` だけが持つ。Render は時計を読まない。`FloorReducer.tick`、`StepPace`、視野の平面 0.7、目の 0.46 は変えない。ゲートは、水平線 0 がこれまでの壁帯と一致すること、正のずれで床が広がること、負のずれで天井が広がること、疑似 3D の絵がそれに従うこと、平面の絵がずれないことをテストする。

## 結果

階が変わる数枚だけ、降りるときは床が、上るときは天井が広がる。次の階は中央に戻る。同じシードなら同じ絵になる。ワープ、掘削、ボス階、最深記録、宝箱のミミックは、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 目を上下に動かす | 壁の中へ進めることを ADR 0003 は退けた。画面上の水平線をずらす方が、マスの中にいたまま床か天井が広がる |
| 普段の一歩でもずらす | 廊下と階段の絵が区別できなくなる |
| 次の階を傾けてから中央へ戻す | 動き終わった次の階は、中央のまま見せる |
| 待ちを `WalkTempo` に通す | 階段前の 7ms で絵が消える。この絵は歩調とは別である |
| 167ms の到着か旋回を短くする | 階が変わったあとの絵と、向きを見る拍が消える |
| 4 枚の前進をこの絵に置き換える | 階段へ近づく動きと、階が変わる動きは別である |
| 平面にも水平線を足す | 平面に消失点はない。`<` `>` と階の数字のままにする |
| `paint` に引数を足す | 引数は 4 つまで。ずれは視線が持つ |
