# ADR 0020 — n で下の階へ落ちる

- 状態: 受理
- 日付: 2026-10-25
- Issue: #65
- 影響する規則: ARC-001 / ARC-007 / ARC-011 / ARC-012 / SWF-002

## 文脈

階を降りるのは、走者が下り階段へ着いたときだけである。広い階ではそこまでが長い。施主は、ボタンを押したら下の階へ強制移動したい、と述べた。次の階を作るのは `FloorReducer.nextFloor`、消失点をずらすのは疑似 3D で階が変わるときの既存の経路である。

## 決定

`n` と `N` は、いまの升にいたまま下の階を開く。戦闘、水面、ワープ、掘削の途中でも、その拍で効く。開く階、歩調、消失点、掘削は、下り階段に着いて降りたときと同じ `nextFloor` である。上の階へは飛ばない。

## 強制

キーの意味は `Keystroke` だけが決める。落ちる状態は `WalkAim.drop` だけが持ち、`FloorReducer.tick` がそれを `.descended` にする。次の階は `nextFloor` 以外が作らない。Render は時計もキーも読まない。ゲートは、`n` と `N` が下りであること、待ちが残っていても位置と歩数を変えずに降りること、開く次の階が同じ世界の `nextFloor` と一致することをテストする。

## 結果

広い階を、階段まで歩かずに飛ばせる。宝箱と戦闘の報酬は、その階では入らない。次の階の体力は、階段で降りたときと同じく回復する。最深記録は次の階まで進む。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 別の生成で次の階を作る | 階段の降りと階がずれる |
| 戦闘や掘削が終わるまで待つ | 強制にならない |
| 同じキーで上の階へも飛ぶ | 施主が求めたのは下の階である |
| HUD に操作の説明を足す | HUD は 5 行のままである。`t` と `v` も説明を持たない |
