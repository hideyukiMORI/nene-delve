# ADR 0008 — 階段の手前の一歩だけ 7ms にする

- 状態: 受理
- 日付: 2026-10-25
- Issue: #39
- 影響する規則: ARC-001 / ARC-007 / ARC-012

## 文脈

ADR 0005 は直線を 14ms にし、ADR 0006 は部屋を少なくとも 112ms にし、ADR 0007 は行き止まりを 167ms にした。階段の手前はどれにも当たらず、広い階の直線では 14ms のままである。種類 A の階段は部屋の中に置かれるので、部屋の待ちが先だと加速は起きない。施主は階段前の加速を残している。降りる絵は別の残りである。

## 決定

次の升が階段か、階段の直交の隣でいまより近いとき、その一歩は `StepPace.sprint` の 7ms である。部屋の待ちと疑似 3D の静止より短くする。すでに 7ms より短い待ちは延ばさない。遠い一歩、足を止めている拍、降りたあとの階は変えない。向きを変える拍は 167ms のままである。3D の途中の 4 枚は残し、階段の手前だけその待ちを 7ms にする。`forSpan` は変えない。

## 強制

階段の手前かどうかは `StairApproach` だけが決め、待ちの選択は `WalkTempo` だけが行う。次の升は `FloorReducer.tick` の結果だけを見る。実行ファイルは時計を読んで待ちを選ばない。ゲートは、隣へ近づく一歩と階段へ乗る一歩が 7ms、遠い直進が 14ms、部屋で階段へ向かわない一歩が 112ms、戦闘が階の歩調、広い階の `forSpan` が 28ms であることをテストする。

## 結果

階段が見えたあとの二歩が、平面でも疑似 3D でも 7ms になる。部屋の中でも階段へ向かう一歩は 112ms にならない。上り、ワープ、降りる演出は、この決定では特別にしない。

## 却下した選択肢

| 選択肢 | 却下の理由 |
| --- | --- |
| 階段の手前で 3D の途中の絵を消す | 速さをフレームの間引きで作ることになる。絵は残し、待ちだけを変える |
| 手前を 14ms のままにする | 広い階の直線と区別がつかない |
| 階の全体を 7ms にする | 角と戦闘まで追えない |
| 部屋の 112ms を優先する | 種類 A の階段は部屋の中にあり、加速が起きない |
| 階段に乗ったあとの降りる絵も 7ms にする | 降りる演出は別の残りである |
| 旋回の 167ms も短くする | 向きを見る拍まで消える |
